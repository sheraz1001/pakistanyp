# PakistanYP — Pakistan Yellow Pages (pakistanyp.com)

The business directory for Pakistan: 7 provinces and territories, 460+ cities and towns,
800+ localities and about 1,570 categories across 22 sectors.
React + Vite + Express with server-side rendering, on PostgreSQL (Neon).

- Deploy guide: [DEPLOY.md](DEPLOY.md)
- Brand guidelines: [BRAND.md](BRAND.md)
- Site settings (brand, domain, +92, PKR, colours, logo files): `shared/country.ts`
- Places: `shared/countries/pakistan-places.ts`
- Categories: `shared/countries/pakistan-categories.ts`

```bash
npm install
npm run dev      # development
npm run build    # production build
npm start        # production server
```
