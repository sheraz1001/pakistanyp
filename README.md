# PakistanYP — Pakistan Yellow Pages (pakistanyp.com)

The business directory for Pakistan: every province and territory, its cities and towns and
their localities, and a full category tree written for the Pakistani market.
React + Vite + Express with server-side rendering, on PostgreSQL (Neon).

- Deploy guide: [DEPLOY.md](DEPLOY.md)
- Site settings (brand, domain, +92, PKR, colours, logo files): `shared/country.ts`
- Places: `shared/countries/places.ts`
- Categories: `shared/countries/categories.ts`

```bash
npm install
npm run dev      # development
npm run build    # production build
npm start        # production server
```
