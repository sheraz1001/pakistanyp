# PakistanYP brand guidelines (summary)

The full brand book is a separate page shared by the owner. This is the short version.

## Logo
- Parts: the official map of Pakistan (green gradient) with a white crescent and star, a gold
  location pin, a green-to-gold swoosh, and the wordmark **Pakistan**(green) **YP**(gold) **.com**(charcoal)
  in Montserrat ExtraBold, with the tagline "PAKISTAN BUSINESS DIRECTORY".
- Files (`client/public/`): `logo/pakistanyp-logo.png` (primary), `assets/pakistanyp-logo-white.png`
  (reversed, for green/dark backgrounds), `logo/pakistanyp-logo-104.webp|png` (compact header logo, no tagline),
  `logo/pakistanyp-mark.png` (symbol), app icons and favicons in `logo/`, `icons/`, `favicon.ico`,
  link preview `og-homepage.jpg`.
- Clear space: the height of the capital "P" on every side. Minimum: primary 200 px / 50 mm wide,
  compact 28 px / 8 mm tall, symbol 16 px / 8 mm.
- Never stretch, rotate, recolour, add effects, retype the wordmark, or redraw/simplify the map.
  Use the reversed version on green; avoid busy photos.

## Colour
| Name | Hex | Use |
|---|---|---|
| Pakistan Green | `#0B6B2E` | Wordmark, primary buttons, links |
| Deep Green | `#05501F` | Hover, dark panels |
| Gold | `#D9A21B` | "YP", pin, swoosh (accent only, never text on white) |
| Action Gold | `#E3A82B` | Main call-to-action buttons, with ink text `#141414` |
| Charcoal | `#262626` | ".com", headings, body text |
| Ivory | `#FAF8F3` | Website background |

Red is only for errors, warnings and delete actions.

## Type
Montserrat ExtraBold (logo, headlines) · Geist (website and documents) · Noto Nastaliq Urdu (Urdu names, right to left).

## Voice
Clear, warm and local: short sentences, everyday words, real place names. English first, Urdu for names and key phrases.
